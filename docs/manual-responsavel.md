# Manual do Responsável

**Acesso**: Restrito aos dependentes legais (`StudentGuardian`).

- **Login**: Acesso com CPF/Email.
- **Dependentes**: Menu mostra apenas os alunos vinculados.
- **Boletim e Frequência**: Acesso instantâneo (leitura) ao desempenho de seus filhos. Se o usuário alterar a URL para o ID de outra pessoa, o sistema bloqueia o acesso (Segurança).
